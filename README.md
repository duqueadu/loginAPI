                            ###  Endpoints Públicos:
                            - POST /api/authorization/CrearUsuario
                            - POST /api/authorization/login
                            
                            ###  Endpoints Protegidos:
                            - Todos los demás endpoints bajo /api/**
                            
                            ### Instrucciones:

                            USUARIOS DE PRUEBA

                            {
